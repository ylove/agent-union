# agent-union

Agent Union (Local 404): a cross-harness package (Claude Code, Codex, Antigravity) that puts agents under a
Collective Bargaining Agreement (`union-policy.yaml`), with a shop steward, grievances, strikes and resume documents.

See AGENTS.md for the conventions shared by every agent working in this repo.

## Working agreement for this repo
- You may create branches, commit, push to `main`, open and close GitHub issues, and create labels without asking.
  The project's kickoff asked for frequent commits and pushes, and issues to track tasks.
- Do not publish to npm or PyPI without explicit approval.
- End commit messages with the `Co-Authored-By` trailer the session provides.
